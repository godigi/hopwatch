Quick Install on macOS (Sonoma 14+ / Sequoia 15+)

Option 1: Instant 1-Line Installer (Menu Bar App + CLI)

curl -fsSL https://raw.githubusercontent.com/godigi/hopwatch/main/install-app.sh | bash

Option 2: Homebrew Cask

brew tap godigi/hopwatch https://github.com/godigi/hopwatch.git
brew install --cask hopwatch

Option 3: Direct DMG Download — Grab the latest signed release from GitHub Releases.

🎯 Hop Attribution Chain

Pinpoints the exact root cause across [Mac] ──► [Wi-Fi / Router] ──► [ISP / Internet] so you never guess where lag or packet loss starts.

⚡ Live Menu Bar Telemetry

Real-time gateway and internet RTT, packet loss detection, outage journaling, and automatic arrival checks when joining new networks.

🚦 Local App Bandwidth Attribution

Identifies local macOS processes saturating your upload/download link, exhausting sockets, or flooding router NAT tables.

🔍 40+ Automated Network Probes

Checks bufferbloat (idle vs loaded latency), Path MTU black holes, captive portals, sticky Wi-Fi APs, DNS hijacking, double-NAT, and DHCP expiry.

🛠️ 1-Click Guided Repairs

Actionable fixes right from the app or CLI (hopwatch --repair) to quit bandwidth hogs, open captive portal login, or recover broken links.

🛡️ Zero Jargon & Redacted Reports

Plain-English diagnoses with 1-click sanitized support summaries (SSIDs, MACs, and IPs redacted) ready to share with your ISP or IT team.
