# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please use GitHub's [Private Vulnerability Reporting](https://github.com/godigi/hopwatch/security/advisories/new) feature on the repository.

### What to Include

Please provide:
- A description of the vulnerability and potential impact.
- Step-by-step reproduction instructions or a minimal proof-of-concept.
- Affected components (CLI, GUI, installer, or background services).

### Our Commitment

- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide an assessment and timeline for a patch.
- Once fixed, we will credit your responsible disclosure in the release notes (unless you prefer to remain anonymous).
